# Política de Seguridad / Security Policy

## Versiones con Soporte / Supported Versions

Actualmente, *Craft to Nation* se encuentra en fase de desarrollo activo y validación de prototipos. Únicamente la rama principal (`main`) recibe revisiones de seguridad y correcciones activas.

| Versión / Rama | Soportada |
| :--- | :--- |
| `main` (Godot 4.7 / Web) | :white_check_mark: Sí |
| Versiones anteriores / tags archivados | :x: No |

---

## Cómo Reportar una Vulnerabilidad / Reporting a Vulnerability

La seguridad de nuestra comunidad y de la infraestructura del proyecto es fundamental. Si descubres una vulnerabilidad potencial de seguridad en el código del juego, en los scripts de automatización o en el sitio web oficial, **por favor NO abras un Issue público**.

### Procedimiento de Reporte Responsable

1. **Vía GitHub (Recomendado):** Dirígete a la pestaña [Security Advisories](https://github.com/gigalipa/craft-to-nation/security) de este repositorio y utiliza la opción **"Report a vulnerability"** (si está habilitada en tu cuenta) para abrir un reporte privado y confidencial.
2. **Vía Correo Electrónico:** Envía un correo directamente a:
   - ✉️ **`crafttonation@gmail.com`**
   - Asunto: `[Vulnerabilidad de Seguridad] Craft to Nation - <resumen breve>`

### Información a Incluir en el Reporte

Para evaluar y resolver el problema con rapidez, incluye:
- Descripción clara de la vulnerabilidad y su impacto potencial.
- Pasos detallados para reproducirla o código de prueba de concepto (*PoC*).
- Componente o entorno afectado (código Godot, sitio web Netlify, dependencias o herramientas).

### Compromiso de Respuesta y Divulgación Coordinada

- **Acuse de recibo:** Confirmación de recepción en un plazo máximo de **48 horas**.
- **Evaluación y resolución:** Mantendremos comunicación directa con quien reporte mientras se investiga, mitiga y valida la solución.
- **Agradecimientos:** Salvo que prefieras el anonimato, acreditaremos debidamente tu aporte en las notas de la versión tras publicar la corrección.
